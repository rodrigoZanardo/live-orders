# Deploy on Render (free plan)

The [render.yaml](../render.yaml) Blueprint creates three things: `live-orders-api` and `live-orders-web` (Docker web services) and `live-orders-redis` (a free Key Value instance). The database is the existing free Postgres, shared with other projects through its own schema.

## Free plan limits that matter here

| Limit | Effect | How the app copes |
|---|---|---|
| Services sleep after 15 min idle | The first request can take about a minute | The web retries reads on 502/503/504 for about 40 s |
| Key Value: 25 MB, 50 connections, **no persistence** | A restart empties Redis and its queued jobs | Events live in Postgres; boards catch up by `seq`. A PENDING webhook delivery is queued again after 2 min. A late timer lost in a restart is not restored: the order is simply not flagged |
| One free Postgres | Shared with Stock Manager | `DATABASE_URL` ends with `?schema=live_orders` |

## Steps

1. **Blueprint:** Render dashboard, then New, then Blueprint, then pick `rodrigoZanardo/live-orders`.
2. **Secrets** (`sync: false`), set in the dashboard or with `PUT /v1/services/{id}/env-vars/{key}`:
   - `DATABASE_URL`: the external connection string of the shared Postgres, plus `?schema=live_orders`.
   - `ADMIN_EMAIL` and `ADMIN_PASSWORD`: the real admin. Keep the password private.
   - `DEMO_PASSWORD`: the same value on both services. `demo@example.com` is created as STAFF.
   - `WEB_ORIGIN` on the API: the web URL. `API_URL` and `PUBLIC_API_URL` on the web: the API URL. Read the real URLs from the Render API, because names can get a suffix.
3. **Deploy:** the API runs `prisma migrate deploy` before it starts.
4. **Smoke test:**
   - `GET <api>/health` returns `{"status":"ok"}`.
   - Sign in as the demo user on `<web>/login`.
   - Open the board in two windows and move an order.
5. **Demo orders:** `WEBHOOK_INCOMING_SECRET` is generated by Render. Read it from the API service's environment and run:
   ```bash
   API_URL=<api> WEBHOOK_INCOMING_SECRET=<value> node scripts/delivery-platform.mjs
   ```
